# Optional global policy: capture useful work

Adopt only with the owner's explicit authorization.

At the end of useful completed software configuration or operational work, ask
once whether the user wants a reusable global skill/workflow. Honor existing
answers. Build the complete standalone package before offering upstream
submission. Check the latest published LocalSetup contract and record the exact
release and evidence. Keep framework integration optional and private state out.

Once the package is complete and checked, ask whether the user wants a feature
request submitted to CruxExperts/LocalSetup. Existing explicit authorization
covers the step; do not ask again. Submit only with approval, including full
compressed source, digest, checks, compatibility and integration instructions,
and a verified maintainer-accessible download. Do not merge or release it.
