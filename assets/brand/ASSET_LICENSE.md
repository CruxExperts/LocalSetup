`banner-reference.png` is a version-free derivative of the banner supplied by
the user for this identity replacement. The reference's release number is not
part of the visual identity. This old reference remains design evidence;
current outputs use the reviewed visible-work plates and contain no versions.
`space-background.png` was generated with the built-in image tool
(`gpt-image-2-codex`) using that banner as the visual reference. The prompt
requested a nearly black navy star field, subtle blue nebula wisps, sparse stars
and a faint blue planetary rim, with no text, logos, cards, wires or icons.
That background remains an earlier design reference and is no longer used by
the current renderer. New marketing sources live in `plates/`, with hash-bound
provenance and [production briefs](PROMPTS.md). Only delivery resampling and
metadata are applied to those compositions. Diagrams are rendered from code.

The square mark and social preview are current artwork, not replacements for
the immutable historical release logo. Uploading the social preview or changing
repository settings requires a separate publication step.
