## Shared direction

Retain the recognizable blue bracket `[LS]` mark and exact LocalSetup spelling
from the earlier hero, while replacing its dark space theme and old content.
Use luminous technical instrumentation: cool-white and pale ice-blue surfaces,
navy lettering, electric azure accents, generous whitespace, and precise
technical typography. Show existing agent tools connected to a LocalSetup
foundation, a visible terminal observation lane, and selected OpenPGP workflows.
No starfields, gradient text, cyberpunk, padlock/shield clichés, humanoids,
vendor logos, release numbers, or claims of universal encryption. Keep all text
legible and within generous safe margins. Finished standalone artwork, not a
device mockup. Rights belong in metadata rather than tiny visible legal text.

## Light hero

Requested landscape 2048×768. On the left: `[LS] LocalSetup`, then the large
two-line headline **“See the work.” / “Keep control.”**, followed by
**“The harness for your agent harness.”** The lower line reads
**“Visibility · Security · Privacy”**. On the right: the tool stack and terminal
lane, labelled **“Your agent tools”**, **“LocalSetup”**, **“Live operations”**, and
**“OpenPGP workflows”**. Terminal rows read **“build   running”** and
**“tests   passed”**. Favor clear details over dense decorative panels.

## Diagram typography

Architecture and installation diagrams use the existing SVG/Python renderer and
pinned JetBrains Mono fonts. Generated marketing lettering is part of the raster
plates; it is not represented as a verified JetBrains font render. Theme tokens
control the code-rendered diagrams.
