# LocalSetup 4.47.10

LocalSetup 4.47.10 updates the locked OpenTelemetry API package from 1.44.0 to 1.45.0. No LocalSetup command or feature behavior changes.

## Highlights

- **Keep project sync reproducible:** update the OpenTelemetry API lock entry through the existing uv workflow.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v4.47.10) for release assets.

## Compatibility

No LocalSetup CLI, configuration, or persisted-state compatibility changes are introduced by this release.

OpenTelemetry API 1.45.0 requires custom `Logger` subclasses to implement `enabled()`. LocalSetup's Python sources do not import the OpenTelemetry API or define such subclasses. Consumers that subclass `opentelemetry._logs.Logger` from this environment should review the [upstream 1.45.0 changelog](https://github.com/open-telemetry/opentelemetry-python/blob/v1.45.0/CHANGELOG.md).

The existing SDK paging and Agent Q v2/envelope compatibility changes remain in effect; see the [4.44.1 release guide](4.44.1.md) before migrating those consumers.

The framework command and Python distribution remain `localsetup`; the integrated CLI remains `lscli`. The corrected 4.x major-line lock remains active.

## Update

For an explicit source directory or extracted release archive, use `--sync-env` to provision the locked Python runtime. See the [multi-platform install guide](../MULTI_PLATFORM_INSTALL.md) for adapter selection and bootstrap behavior.

Use the [versioning guide](../VERSIONING.md) for corrected 4.x release policy and historical tag treatment.

For installation and source refresh, read the [quickstart update instructions](../QUICKSTART.md#update). Adapter changes follow the [adapter ownership guide](../ADAPTER_OWNERSHIP.md).

## Verify the download

Before publication, require the complete Python test suite, the documented automated smoke suite, all required GitHub checks on the exact candidate, and the signed release tag against the accepted source commit. The published archive must include `.sha256` and `.cdx.json` sidecars.

Download the framework archive with both its `.sha256` checksum and `.cdx.json` SBOM sidecars. Keep all three files in the same directory before running `verify-release`.

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v4.47.10.tar.gz
```
