# LocalSetup 4.89.13

LocalSetup 4.89.13 repairs controlled Herdr shell startup, safely recovers verified completed pane generations, and gives managed operations children their intended share of the terminal.

## Highlights

- Controlled Bash startup uses a private startup-home overlay so the managed handler loads after the real login profile, including profiles that replace PROMPT_COMMAND. The handler restores the real home and keeps credential filtering and primary-prompt admission checks intact.
- Completed managed pane generations can be recovered only after native identity, durable operation records and ownership establish a safe transition. Reconciliation retains the completed operation identity when its pane has disappeared, allowing one verified replacement. Busy, conflicting and uncertain states remain read-only; recovery does not clear input, adopt an unrelated pane or replay an uncertain command.
- The managed child fraction is converted to Herdr's native parent-pane ratio. An operations child occupies one third of the caller's original height, while the durable owner record preserves the child fraction and ordinary non-managed splits keep their existing behavior.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v4.89.13) for release assets.

## Compatibility

This maintenance release preserves the public managed-terminal API and persisted child-fraction meaning. Existing uninstrumented or uncertain panes are not automatically adopted or replaced.

The release retains the published 4.89.10 dependency baseline; unrelated pending dependency and routing-catalog changes are not included.

Routing resource contents and review-expiry checks are unchanged; expired capability data still fails closed.

## Update

Use the normal verified installation or dependency-update procedure for the published archive. Consumers with immutable workflow exports must regenerate and verify their export from the accepted source and lock revision before using the new runtime.

Reconcile an existing uncertain operation before changing its pane. A corrected startup path does not make an old uninstrumented shell safe for input.

For installation and source refresh, read the [quickstart update instructions](../QUICKSTART.md#update). Adapter changes follow the [adapter ownership guide](../ADAPTER_OWNERSHIP.md).
