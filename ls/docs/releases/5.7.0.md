# LocalSetup 5.7.0

LocalSetup 5.7.0 gives its GitHub documentation a consistent light and dark visual identity. The README hero and current architecture and installation diagrams use the approved LocalSetup palette, mark, and typography while retaining their technical content and accessible descriptions.

## Highlights

- **Theme-aware graphics:** The README hero, architecture diagram, and installation flow each have light and dark images selected by GitHub's color scheme. Existing light image paths remain valid.
- **Reproducible brand assets:** The graphics renderer uses approved tokens and pinned JetBrains Mono v2.304 Regular and SemiBold files. The original font license and hashes are recorded with the source.
- **Asset inventory and brand contract:** Documentation checks recognize images in picture sources, and the brand guide records the visual rules and future AstroSite handoff. Nerd Font glyphs remain an optional site profile.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v5.7.0) for release assets.

## Compatibility

The framework command and Python distribution remain `localsetup`; the integrated CLI remains `lscli`. No installation or runtime command changes are required for this visual update.

Existing light image filenames remain available for links and renderers that do not support theme selection. Historical release artwork is unchanged.

## Update

Update a registered installation using the [quickstart instructions](https://github.com/CruxExperts/localsetup/blob/v5.7.0/ls/docs/QUICKSTART.md#update). The branding changes are visible in the repository documentation and do not require a configuration migration.

For graphics maintenance, use the [branding guide](https://github.com/CruxExperts/localsetup/blob/v5.7.0/ls/docs/BRANDING.md) and the pinned renderer. Keep the separate AstroSite implementation aligned with the documented visual contract.

For installation and source refresh, read the [quickstart update instructions](../QUICKSTART.md#update). Adapter changes follow the [adapter ownership guide](../ADAPTER_OWNERSHIP.md).

## Verify the download

Download `localsetup-v5.7.0.tar.gz`, `localsetup-v5.7.0.tar.gz.sha256`, and `localsetup-v5.7.0.tar.gz.cdx.json` together. Follow the [release guide verification steps](https://github.com/CruxExperts/localsetup/blob/v5.7.0/ls/docs/releases/5.7.0.md#verify-the-download) to run `verify-release` and confirm the signed `v5.7.0` tag points to the release commit.

Maintainers check the six graphics against the pinned renderer, validate archive and font hashes and licensing, inspect both GitHub color themes, and run the documentation and Python checks before publishing.

The GitHub repository description and social preview are presentation settings; the social image source remains in private maintenance state and is not part of the release archive.

Download the framework archive with both its `.sha256` checksum and `.cdx.json` SBOM sidecars. Keep all three files in the same directory before running `verify-release`.

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v5.7.0.tar.gz
```
