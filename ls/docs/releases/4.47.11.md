# LocalSetup 4.47.11

LocalSetup 4.47.11 updates the managed cryptography runtime from 50.0.1 to 50.0.2 in both the project environment and packaged LSCli SDK runtime. The 50.0.2 wheels use OpenSSL 4.0.3, outside the affected versions in the 2026-09-29 OpenSSL advisory; LocalSetup direct call paths do not use the listed specialized protocols. No LocalSetup command or API behavior changes.

## Highlights

- **Update the packaged cryptography runtime:** resolve cryptography 50.0.2 in the project and LSCli SDK locks; its wheels bundle OpenSSL 4.0.3, outside the advisory-affected range.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v4.47.11) for release assets.

## Compatibility

The pyca 50.0.2 changelog reports no Python API changes. The declared requirement remains `cryptography>=50.0.0`; the managed environment resolves 50.0.2.

The 50.0.2 wheels bundle OpenSSL 4.0.3, outside the affected 4.0.0–4.0.2 versions in the [2026-09-29 OpenSSL advisory](https://openssl-library.org/news/secadv/20260929.txt). LocalSetup direct call paths do not use the listed specialized protocols.

No LocalSetup CLI, configuration, or persisted-state compatibility changes are introduced by this release.

The existing SDK paging and Agent Q v2/envelope compatibility changes remain in effect; see the [4.44.1 release guide](4.44.1.md) before migrating those consumers.

The framework command and Python distribution remain `localsetup`; the integrated CLI remains `lscli`. The corrected 4.x major-line lock remains active.

## Verify the download

Before publication, require the complete Python test suite, the documented automated smoke suite, all required GitHub checks on the exact candidate, and the signed release tag against the accepted source commit. The published archive must include `.sha256` and `.cdx.json` sidecars.

Download the framework archive with both its `.sha256` checksum and `.cdx.json` SBOM sidecars. Keep all three files in the same directory before running `verify-release`.

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v4.47.11.tar.gz
```
