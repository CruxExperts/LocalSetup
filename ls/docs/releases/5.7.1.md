# LocalSetup 5.7.1

LocalSetup 5.7.1 gives its GitHub documentation a consistent light and dark visual identity and clarifies the canonical repository name as CruxExperts/LocalSetup. The README hero and current architecture and installation diagrams use approved LocalSetup branding, with reproducible rendering and accessible descriptions.

## Highlights

- **Theme-aware graphics:** The README hero, architecture diagram, and installation flow each have light and dark images selected by GitHub's color scheme. Existing light image paths remain valid.
- **Reproducible brand assets:** The graphics renderer uses approved tokens and pinned JetBrains Mono v2.304 Regular and SemiBold files. The original font license and hashes are recorded with the source.
- **Asset inventory and brand contract:** Documentation checks recognize images in picture sources, and the brand guide records the visual rules and future AstroSite handoff. Nerd Font glyphs remain an optional site profile.
- **Canonical repository spelling:** The maintainer policy identifies `CruxExperts/LocalSetup` as the GitHub repository name and preserves existing repository URL paths and compatibility identifiers.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v5.7.1) for release assets.

## Compatibility

Existing repository URL paths, the framework command, and the Python distribution keep their established spelling.

This documentation clarification requires no installation or configuration migration.

Update a registered installation using the [quickstart instructions](https://github.com/CruxExperts/localsetup/blob/v5.7.1/ls/docs/QUICKSTART.md#update).

For installation and source refresh, read the [quickstart update instructions](../QUICKSTART.md#update). Adapter changes follow the [adapter ownership guide](../ADAPTER_OWNERSHIP.md).

## Verify the download

Download `localsetup-v5.7.1.tar.gz`, its `.sha256` checksum, and `.cdx.json` SBOM sidecar together. Follow the [release guide verification steps](https://github.com/CruxExperts/localsetup/blob/v5.7.1/ls/docs/releases/5.7.1.md#verify-the-download) to run `verify-release` and confirm the signed `v5.7.1` tag points to the release commit.

Before publishing, inspect both theme variants of the current graphics, check the pinned renderer and font hashes and license, and run the documentation and Python checks.

No runtime or installer behavior changes in this documentation update.

Download the framework archive with both its `.sha256` checksum and `.cdx.json` SBOM sidecars. Keep all three files in the same directory before running `verify-release`.

```bash
uv run --locked python ls/tools/localsetup.py --source-root . verify-release /path/to/localsetup-v5.7.1.tar.gz
```
