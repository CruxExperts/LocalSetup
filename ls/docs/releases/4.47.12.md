# LocalSetup 4.47.12

LocalSetup 4.47.12 clarifies the LSCli file broker size contract for sealed OpenPGP sources. The 8 MiB limit applies to the complete stored encoded source; verified plaintext has a separate 16 MiB limit. Consumers must check encoded size before acknowledging publication. Page and response bounds are unchanged; runtime behavior is unchanged.

## Highlights

- **Clarify sealed-source admission:** the 8 MiB limit covers the complete armored or binary source, verified plaintext remains limited to 16 MiB, and consumers must check encoded size before acknowledging publication.

After publication, see the [release and downloads](https://github.com/CruxExperts/localsetup/releases/tag/v4.47.12) for release assets.

## Compatibility

The 8 MiB source limit includes every byte of the stored sealed envelope. Sealing may expand a plaintext that otherwise fits; consumers must check the complete encoded source against 8 MiB before acknowledging publication. The separate verified-plaintext limit remains 16 MiB.

Existing page bounds remain 200 LF-delimited lines and 8 KiB of page-content bytes before response serialization; the complete serialized response remains capped at 16 KiB.

This is a documentation clarification; no runtime code or API behavior changes.
