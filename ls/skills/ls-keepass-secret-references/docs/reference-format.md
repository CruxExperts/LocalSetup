# Reference Format

Supported forms:

```text
Secret ID: mail.box03.example.admin
{{secret:mail.box03.example.admin:password}}
secret://localsetup/repo/default/mail.box03.example.admin#field=password
```

Canonical IDs are lowercase and may contain digits, dots, underscores, and hyphens. Email-like aliases are supported through map files and resolve to canonical IDs.
