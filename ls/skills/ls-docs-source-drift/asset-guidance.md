# Asset Guidance

The asset manifest is generated at `ls/docs/_generated/docs-asset-manifest.json`.

`assets/README.md` records:

- asset path
- type
- dimensions when discoverable
- Markdown references
- provenance
- license notes

Do not vendor GitHub, Primer, Octicon, Mona Sans, Hubot Sans, or other brand assets into this repo unless a separate license review explicitly approves it.

Create new SVG or Mermaid diagrams only when they clarify architecture or workflow. Prefer existing assets when they already explain the concept.
