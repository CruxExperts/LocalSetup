# Form Rules

- Prefer `FieldGroup`, `Field`, `FieldSet`, `FieldLegend`, `FieldLabel`, and
  `FieldDescription` for new form layout.
- Wire invalid state with `data-invalid` and `aria-invalid`.
- Use `InputGroupInput` and `InputGroupTextarea` inside `InputGroup`.
- Keep validation messages close to their fields and accessible.
- Treat Select, Combobox, Calendar, Date Picker, Slider, Switch, Checkbox, and
  Radio Group as controlled form components, not raw text inputs.
