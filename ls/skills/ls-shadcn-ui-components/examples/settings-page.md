# Settings Page Example

Read first: `components/layout-navigation.md`, `components/forms-inputs.md`, and
`references/theming.md`.

Use Card for grouped settings, Tabs for same-page categories, Field components
for controls, Switch for immediate toggles, and Select/Native Select for
bounded choices.

Failure modes: nested card-heavy layout, switches used for deferred choices,
and state split across too many client components.
