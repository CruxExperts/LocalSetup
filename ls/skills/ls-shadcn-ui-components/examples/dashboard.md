# Dashboard Example

Read first: `components/data-display-dashboards.md`,
`components/layout-navigation.md`, and `references/project-context.md`.

Use Sidebar for app navigation, Card for metric groups, Chart for trends,
Table/Data Table for records, Skeleton for loading, Empty for no data, and Alert
for actionable status.

Failure modes: unstable loading dimensions, chart containers without width,
server data imported into client-only components, and color-only status.
