# Responsive Navigation Example

Read first: `components/layout-navigation.md`, `components/overlays-menus.md`,
and `references/frameworks.md`.

Use Sidebar or Navigation Menu on wide screens and Sheet or Drawer for mobile
navigation. Keep links semantic and ensure focus returns when the panel closes.

Failure modes: duplicated nav data that drifts, hidden links inaccessible by
keyboard, and custom z-index workarounds.
