# Date Picker And Calendar Example

Read first: `components/forms-inputs.md`, `references/forms.md`, and
`references/accessibility.md`.

Use Calendar for date grids and Date Picker patterns for input plus popover or
dialog flows. Keep formatting, time zone decisions, and validation consistent
with the app domain.

Failure modes: ambiguous date formats, hidden labels, and treating selected
dates as strings until the boundary where serialization is required.
