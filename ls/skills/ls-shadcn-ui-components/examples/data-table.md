# Data Table Example

Read first: `components/data-display-dashboards.md` and `references/cli.md`.

Data Table is a pattern, commonly built with TanStack Table. Confirm the docs
and dependencies, then adapt columns, sorting, filters, pagination, and empty
state to the project.

Failure modes: treating Data Table as a simple one-file component, putting all
table state in a server component, and omitting empty/loading states.
