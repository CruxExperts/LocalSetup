# Component Index

Docs pages and registry items are not one-to-one. Always check `docs`, `view`,
and `search` before assuming an item can be installed directly.

| Group | Components and patterns |
|---|---|
| Forms and inputs | Field, Input, Input Group, Textarea, Label, Checkbox, Radio Group, Switch, Slider, Select, Native Select, Combobox, Calendar, Date Picker, Input OTP |
| Buttons and actions | Button, Button Group, Toggle, Toggle Group, Kbd |
| Layout and navigation | Card, Breadcrumb, Navigation Menu, Pagination, Sidebar, Tabs, Resizable, Scroll Area, Separator, Accordion, Collapsible |
| Overlays and menus | Dialog, Alert Dialog, Sheet, Drawer, Popover, Hover Card, Tooltip, Dropdown Menu, Context Menu, Menubar, Command |
| Feedback and loading | Alert, Empty, Progress, Skeleton, Spinner, Sonner, Toast, Badge |
| Data display | Table, Data Table, Chart, Avatar, Item |
| Media and utilities | Aspect Ratio, Typography, Direction |
| Registry patterns | dashboard, login/signup, chart blocks, sidebar blocks, private/custom registry items |

## Per-Component Checklist

For any component, capture:

- docs URL and registry item name when present
- install command or "pattern/example only"
- use cases and non-use cases
- imports and subcomponents
- composition rules and accessibility requirements
- variants, props, and dependencies
- related components
- RSC/client notes
- Base/Radix API differences
- common mistakes
- minimal example and test checklist
