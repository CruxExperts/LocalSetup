# Buttons And Actions

| Component | Use for | Notes |
|---|---|---|
| Button | primary actions | Use variants and sizes first; loading composes `Spinner` and `disabled`. |
| Button Group | related actions | Keep button semantics; avoid overcrowding on mobile. |
| Toggle | two-state action | Provide pressed state and accessible name. |
| Toggle Group | related toggles | Use single or multiple mode intentionally. |
| Kbd | keyboard hints | Display shortcut hints; do not use as an interactive control. |

Prefer icon buttons only when the icon is recognizable and named. Use the
configured icon library.
