# Feedback, Status, And Loading

| Component | Use for | Notes |
|---|---|---|
| Alert | inline status message | Match variant to severity. |
| Empty | empty state | Include the next useful action when appropriate. |
| Progress | determinate or indeterminate progress | Label progress when context is not obvious. |
| Skeleton | placeholder loading | Match final layout dimensions to prevent layout shift. |
| Spinner | inline loading | Pair with disabled actions when submitting. |
| Sonner | toasts | Prefer for transient feedback. |
| Toast | legacy toast pattern | Check project version and docs before adding. |
| Badge | compact status/category | Avoid using color alone to carry meaning. |
